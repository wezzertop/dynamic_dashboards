Getting Started

How to Install

  1. Download the module from the Odoo App Store.
  2. Extract the downloaded file and place the dynamic_dashboards folder into your Odoo addons directory.
  3. Restart your Odoo server.
  4. Log in to your Odoo database as an Administrator.
  5. Activate Developer Mode (Settings > Activate the developer mode).
  6. Go to the Apps menu and click Update Apps List.
  7. Search for Premium Dynamic Dashboards Pro, remove the 'Apps' filter, and click Install.

No extra Python libraries or external dependencies required! Works completely natively with Odoo 17 & 18.

Step-by-Step Guide

How to Use the Dashboards

1. Create a Board

Navigate to the Dashboards menu. Under Configuration, select Dashboards Boards and create a new board (e.g., "Executive Sales").

2. Generate Widgets Automatically

Click the Smart Generator button. Select any Odoo model (like 'Sales Order'). The system will instantly scan the database fields and generate 6 ready-to-use charts.

3. Create Custom Widgets Manually

Go to Dashboard Items, click New. Pick your Model, define a domain/filter, select a Measure (Sum/Count/Avg), and select a Group By field (e.g., Salesperson). Choose your Chart Type (Pie, Bar, Line, KPI, List).

4. Organize & View

Open your Dashboard Board view. Click the Magic Wand icon in the header to Auto-Organize the grid, placing KPIs on top and large charts below. Use drag & drop to resize!

Overview & Architecture

Core Functionalities in Detail

Global Dashboard Filtering

The global header panel allows you to apply Real-Time Date Filters (Today, This Week, This Month, This Year, Custom Range). These filters apply instantly across all charts in the dashboard, giving you a synchronized snapshot of your data.

Chart Copying System

Don't rebuild from scratch! Use the options menu on any widget to Copy Chart. This instantly duplicates the configuration and allows you to attach it to a different dashboard board in one click.

Data Export (CSV & PNG)

Present your findings in meetings effortlessly. Every widget features an export menu allowing you to download a high-resolution PNG Image of the graph, or a raw CSV Excel File of the underlying grouped data.

Supported Visualizations & Use Cases

Choose the perfect visualization to analyze and share your data trends.

KPI Cards

Shows a single, large aggregated metric. Best for high-level targets like Total Monthly Sales, or Pending Opportunities.

Bar Charts

Renders category comparisons side-by-side. Best for comparing independent segments like Revenue per Customer or Stock levels.

Line & Area Charts

Connects data points in a curve. Area charts shade the bottom region. Best for time-series progressions like Monthly Revenue Trends.

Pie & Doughnut Charts

Displays shares of a total amount. Best for looking at distributions like Sales by Product Category or Lead Sources.

Data Tables (Lists)

Renders a clean grid list of categories and numbers. Best for displaying lists like Top 10 Selling Products or Top Confirmed Orders.

Interactive Drill-Down

Clicking any chart segment or list row opens the underlying Odoo record view, pre-filtered by that specific category and date range.

Toggle Gridlines, Legends, Rounded Bar Corners, Line Smoothing, Render Animations, and Data Labels. All settings are saved directly in browser localStorage per widget. Toggling dark mode or updating parameters preserves your color and design settings exactly!
