# Premium Dynamic Dashboards Pro

Turn your Odoo Community data into powerful, real-time Business Intelligence dashboards.

## Overview
This module allows users to build custom, dynamic dashboards natively inside Odoo using the modern OWL framework and Chart.js.

### Key Features
- **Intuitive Builder:** Create KPI cards, Bar Charts, Pie Charts, Line Charts, and Doughnut Charts.
- **Any Data Source:** Fetch data from Sales, Inventory, Invoices, CRM, HR, or any custom Odoo model.
- **Pre-Built Value:** Comes with 3 pre-configured dashboards (Sales, Inventory, Purchases) so users get immediate value upon installation.
- **Modern UI:** Built on Odoo Web Library (OWL) for high performance and responsiveness.

## Configuration
1. Go to **Dashboards > Configuration > Dashboards Setup**.
2. Click **New** to create a Dashboard Board.
3. Add **Items** (Charts) to your board.
4. Select the **Odoo Model**, the **Chart Type**, and the **Group By** field.
5. Save and view your Dashboard in the main menu!
